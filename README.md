# Instagram 投稿画像の公開置き場

読書記録アカウント [@anne_books88](https://www.instagram.com/anne_books88/) が
投稿するカード画像と動画を置いています。GitHub Pages で配信し、Instagram の
Graph API に公開URLとして渡すためのものです。

- `img/YYYY-MM-DD/NN.jpg` … カルーセルのカード画像
- `img/YYYY-MM-DD/story.jpg` … ストーリー用
- `img/YYYY-MM-DD/reel.mp4` … リールの動画（投稿後に削除されます）

中身は本体リポジトリの GitHub Actions が自動で更新します。
ここを直接編集しても、次回の更新で上書きされます。
